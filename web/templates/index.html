Instructions

  1. Add the URL of an RSS feed below in the Generate Pubkey box and click the button to create a corresponding nostr public key.
  2. If you have an opml file, you can import RSS feeds using the Import link at the top of the page.
  3. Add your rssnotes relay to your Nostr client: wss://{{.RelayURL}}
  4. To follow a single rss feed using nostr scan the feed's qr code or click the qr code to copy the feed's npub. Follow the feed's public key from your Nostr client.
  5. To follow all of the rss feeds on your rssnotes relay: Scan the relay's qr code above, then login to nostr using the relay's public key from your Nostr client.
  6. Some nostr clients also allow your to follow a relay just using the relay url.
  7. For sites missing a feed:
  • Try the url of a standard website in the Generate Pubkey box. rssnotes will search for rss feeds associated with the url.
  • Try using RSS-Bridge.
  • Try using RssHub is capable of generating RSS feeds from pretty much everything too, check it how to use it in https://docs.rsshub.app (ex. repos inside nostr topic in GitHub)
